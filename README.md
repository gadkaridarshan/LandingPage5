# LaunchPad — Landing Page

A polished, conversion-focused landing page template.

## Structure
- `public/index.html` — Hero section markup (USER-87000).
- `public/styles.css` — Design system + Hero styles.
- `public/app.js` — Smooth scrolling, subtle parallax, CTA hooks.

## Hero section (USER-87000)
- Clear headline with gradient accent.
- Supporting subheading that frames the value proposition.
- Primary call-to-action button (`Start free trial`) plus secondary ghost action (`Watch demo`).
- Professional typography hierarchy (Plus Jakarta Sans display + Inter body).
- Accessible contrast-safe palette over a layered gradient + grid + glow background.
- Responsive layout, full keyboard/screen-reader support, respects `prefers-reduced-motion`.

## Run locally
Open `public/index.html` directly, or serve the `public/` directory with any static server, e.g.:

```bash
npx serve public
```
