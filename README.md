# LandingPage5 — Modern Marketing Landing Page

A polished, conversion-focused landing page featuring a hero section, a three-up features showcase, and an accessible contact form — built with semantic HTML5, a shared design-system stylesheet, and vanilla JavaScript. No build step, no framework, no runtime dependencies.

## What it does

LandingPage5 is a self-contained marketing site that introduces a product, highlights its key capabilities, and lets visitors get in touch. It is designed to be fast, accessible, responsive, and easy to adapt.

- **Hero section** — A clear headline, supporting subhead, and primary call-to-action set the tone and drive the visitor toward the next step. Includes polished gradient/grid background treatment, modern typography (Space Grotesk + Inter), and a skip-link for keyboard users.
- **Features section** — Three or more product features are presented as scannable cards, each with an icon, title, and short description, laid out in a responsive grid with consistent spacing and an ambient background that complements the hero.
- **Contact form section** — A labeled name / email / message form with inline client-side validation, accessible error messaging (aria-live regions, `aria-invalid` states), and a non-network submit handler that surfaces a success status message.
